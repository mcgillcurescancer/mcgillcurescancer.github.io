# Skills Archive

This folder holds skills that are currently out of scope for this project.

For the McGill Cures Cancer static fundraising website, active skills should favor simple
static-page UX: clear mission, credibility, impact proof, sponsor/student paths, accessibility,
performance, and restrained visual polish.

Skills moved here are not necessarily bad or deleted permanently. They are archived because they
fit heavier app, dashboard, or complex interaction patterns that should not guide the current site
unless the project scope changes.
